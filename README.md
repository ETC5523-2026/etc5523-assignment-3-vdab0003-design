# Behind the statistic

A personal blog built with Quarto for ETC5523 Communicating with Data at Monash University.

* Author: **Vibhor Dabas**
* Published at: [https://etc5523-2026.github.io/etc5523-assignment-3-vdab0003-design/](https://etc5523-2026.github.io/etc5523-assignment-3-vdab0003-design/)

## Intended audience

The blog post is written for general news readers with no medical or statistical background, who are interested in how health statistics can mislead.

## Generative AI declaration

**Generative AI declaration:** I used Claude (Anthropic) to plan the structure of the website and blog post and to choose and check the accessibility of the site's colour palette. I reviewed all generated code, verified every figure against the original research article, and edited the writing into my own words.

## Repository structure

* `_quarto.yml` — site configuration
* `custom.scss`, `styles.css` — theming
* `index.qmd` — blog listing page
* `about.qmd` — about page
* `posts/` — blog posts
* `docs/` — rendered site, served by GitHub Pages
